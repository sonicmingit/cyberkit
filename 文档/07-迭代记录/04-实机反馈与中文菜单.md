# 04-实机反馈与中文菜单

状态：待实机验证。关联需求：需求-001、需求-003。

## 实机证据与目标

2026-09-08 用户提供首轮设备照片：圆环标签重叠且未按 Figma 原型排布；INFO 点击后设备重启；车载表情可能长期停留；表情上叠加电量；切换表情会短暂闪回待机眼睛。

本轮目标：按图稿重建 360×360 中文六扇区菜单；增加明确“返回桌面”；把摸头触摸、音量、亮度统一放入设备设置；修复 INFO 读取边界、车载瞬态驻留和显示恢复。

## 文件级方案

- `customer_ui/feature_ui.*`：中文菜单几何、菜单注册项、设备设置页、中文车载设置与信息页。
- `CyberVoc.h/.cc`：电量计空句柄保护、串行读取和缓存快照，INFO 不再在点击路径直接访问 I2C。
- `car_mode/car_mode_service.cc`：记录检测事件变化时间，对瞬态事件设置最大显示驻留，断流仍优先。
- `display/emote_display.*`：车载全脸表情期间隐藏电量/状态/时钟；待机状态刷新不再中断车载表情，退出或高优先级状态再恢复原界面。

## 验收边界

- 必须通过主机回归、V2.0 完整构建、资源与合并镜像校验。
- 本轮不自动烧录；中文裁切、六扇区触控、INFO 不重启、IMU 实车阈值和表情无闪回仍需用户刷机复测。
- 参考旧版仅迁移已验证的有界状态/刷新思路，不覆盖 V2.0 QMI8658 驱动、GPIO 或分区配置。

## 实现与验证结果

- 菜单按原型顺时针实现为：功能模板（禁用）、设备设置、系统信息、返回桌面、车载模式、计时器；中心保留时间、日期、车载状态和上滑提示。
- 设备设置已接入摸头触摸开关、音量 10～100 和亮度 10～100；写操作调度到应用任务。
- INFO 只读缓存电量；板级电量读取增加空句柄保护、串行化、输出初始化和最近有效值回退。
- 瞬态显示上限：颠簸 1.0 秒、急刹 1.4 秒、加速/减速 2.6 秒、左右转 4.2 秒；超时视觉回落巡航，传感器断流仍优先显示异常。
- IMU 12/12、菜单与计时器 16/16、CST816S 6/6，总计 34/34 主机探针通过；`git diff --check` 通过。
- ESP-IDF 5.5.2 下完成 V2.0 全量构建、压缩 OTA 和 0x0 合并镜像。app 4,536,368 / 6,144,000、assets 5,351,115 / 5,632,000、model 291,070 / 307,200、压缩 OTA 2,399,744 / 3,072,000 字节；42 个资源、18 个车载表情、83 帧通过校验。
- 264 个 `main` 源码/头文件/配置文件与英文编译快照逐文件 SHA-256 一致。输出版本 2.0.5.8，实机状态仍为待验证。

用户补充要求统一后续表情包目录、中文总览、设计/使用/命名规范及静态 PNG 汇总。本轮已按首次开发顺序登记 `001-TITA大眼仔-v1`、`002-薄荷猫咪-v1`、`003-暖白双眼-v1`，把源固件、视频、提取文件、分镜和提示词移入独立 `源素材/`，三个编号包均采用相同五项交付结构。
