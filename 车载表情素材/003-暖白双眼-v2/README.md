# 003 · 暖白双眼 · v2

`pack_id`: `soft_eyes`

本包是暖白双眼动画的正式候选资源，基于已确认的可爱化过渡方案导出。画布固定为 360×360，纯黑背景，20 FPS 起始设计；正式 GIF 保留 100 个 50 ms 时间槽，EAF 为每 2 个时间槽采样 1 帧（100 ms/帧），用于控制资源体积。

## 状态覆盖

共 19 个状态：唤醒、起步、加速、巡航、待机 1、待机 2、待机 3、左转、右转、回正、倒车、减速、急刹、颠簸、等候/校准、停车、休眠、夜间、信号中断。

`car_idle_01`～`car_idle_03` 是三个独立待机动画：双眨微笑、左右好奇探看、左右交替单眨并害羞微笑。默认等概率在完整播放单元边界选择，至少两项可用时避免立即重复。

## 播放与回退

巡航、三个待机、等候/校准、休眠和夜间建议循环；唤醒、起步、加速、减速、急刹、颠簸、回正、倒车、停车和信号中断结束后交回当前实时状态。左转和右转由可信方向输入保持，结束后恢复当前状态。

缺少或损坏资源时按同包指定状态 → 同包 `car_cruise` → 固件内置中性表情回退。倒车、左右方向及信号中断图标只应在固件已有可信输入时接入，不能由普通 IMU 单独推断。
