## 状态覆盖

| 分组 | 状态 |
|---|---|
| 日常行驶 | `car_wake`、`car_move_off`、`car_accelerate`、`car_cruise` |
| 待机动画组 | `car_idle_01`、`car_idle_02`、`car_idle_03` |
| 方向与机动 | `car_turn_left`、`car_turn_right`、`car_turn_end`、`car_reverse` |
| 路况反应 | `car_decelerate`、`car_hard_brake`、`car_bump`、`car_wait` |
| 驻车与降级 | `car_arrive`、`car_sleep`、`car_night`、`car_signal_lost` |

`car_idle_01` 使用左右交替眨眼，`car_idle_02` 使用大幅左右扫视，`car_idle_03` 使用“睁眼→笑眼+腮红”的完整变化。三个待机动画均为独立完整播放单元，默认等概率选择；随机选择、避免立即重复和失效项过滤由固件待机池负责。

## 转换参数与容量取舍

- 工具：[生成默认表情v1.py](../源素材/004-默认表情-v1/生成默认表情v1.py)，Pillow 12.3.0。
- GIF 完整保留获批方案的 48 个 50 ms 时间槽和 20 FPS。每项动画 2.4 秒，使用共享 256 色调色板且不抖动；编码器会把连续相同画面合并为更长帧时长，因此实际存储为 9～48 帧。
- 无时间采样的 48 帧 EAF 实测合计 13,042,554 字节，超过 5,500 KiB assets 分区；24 帧/32 色版本仍为 5,777,332 字节，超出 145,332 字节。
- 最终 EAF 每 2 个设计时间槽取一个关键帧，保持 2.4 秒轨迹并建议以 100 ms/帧播放；每项使用 24 个有效颜色并填满兼容的 256 项 BGRA 调色板。安全区遮罩后 EAF 合计为 5,407,216 字节，比 5,632,000 字节的分区上限少 224,784 字节。
- `eaf/manifest.json` 记录 EAF/GIF 帧数、建议时长、有效颜色数、时间采样步长、字节数和 SHA-256。EAF 的真实播放间隔仍以播放器设置为准。

## 动作与结束策略

- 常驻循环：`car_cruise`、`car_idle_01`～`car_idle_03`、`car_wait`、`car_sleep`、`car_night`。
- 瞬态动作：其余状态播放后把控制权交回当前实时状态，不恢复过期快照。
- 左右方向以观看屏幕的人为准；转向瞳孔与青色提示朝同一画面方向移动。
- 急刹使用压缩与回弹，颠簸使用两眼反向惯性差；不依赖整屏闪烁表达冲击。

## 使用边界与回退

- `car_reverse` 仅在固件拥有可信倒车输入时接入，不能由普通 IMU 加速度推断。
- `car_night` 是安静的暖黄色风格状态；夜间整体亮度仍由固件统一控制。
- 缺少或损坏的状态按“同包指定状态 → 同包 `car_cruise` → 固件内置中性表情”回退，并记录真实原因。
- v2.0.5.9 已从本包显式复制当前检测器需要的 9 项到 `main/boards/CyberVoc-Board-V2_0/car_packs/default/`：巡航、等待、加速、减速、急刹、颠簸、左右转和传感器异常；其余状态仍只保留在素材库。已完成固件构建和 assets 校验，尚未烧录。
