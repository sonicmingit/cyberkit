| 项目 | 值 |
|---|---|
| `pack_id` | `soft_eyes` |
| 画布 | 360×360，纯黑背景 |
| 状态数量 | 19（16 个设计状态 + 3 个待机动画） |
| 视觉 | 两只暖白双眼；按状态使用青色、黄色、粉色、白色和灰色辅助元素 |
| EAF | 8-bit 索引色 BGRA + RLE，12×30 行分块 |
| 验证状态 | GIF/EAF 结构、清单、360×360、EAF RLE 回读和中文总览已检查；待实机验证 |

本版本按 [v2 设计图](../源素材/003-暖白双眼-v2/v2设计图.png) 提取。设计源图原本位于编号包目录，按新规则已移入 `源素材/`；源图 SHA-256 为 `f15e7b8155bae3dd96c22bbfd9229ba620200e65c0e790698357d235a00a1a67`。

19 个 EAF 合计 2,200,798 字节；该数字是候选文件合计，不代表最终 `assets` 镜像体积。

## 状态覆盖

| 分组 | 状态 |
|---|---|
| 日常行驶 | `car_wake`、`car_move_off`、`car_accelerate`、`car_cruise` |
| 待机动画组 | `car_idle_01`、`car_idle_02`、`car_idle_03` |
| 方向与机动 | `car_turn_left`、`car_turn_right`、`car_turn_end`、`car_reverse` |
| 路况反应 | `car_decelerate`、`car_hard_brake`、`car_bump`、`car_wait` |
| 驻车与降级 | `car_arrive`、`car_sleep`、`car_night`、`car_signal_lost` |

16 个固定状态来自设计图的单姿态展示稿，每个状态生成 4 帧设计衍生动画，用轻微缩放、位移或回弹表达进入/保持；这不是完整 20 FPS 补间动画。`car_idle_01` 是低频眨眼，`car_idle_02` 是左右视线移动，`car_idle_03` 是轻微呼吸与倾斜。三个待机动画各自完整播放一次，默认等概率选择；随机选择、避免立即重复和失效项过滤由固件待机池负责，本候选包未修改固件。

## 转换参数

- 工具：[`工具/生成暖白双眼v2.py`](../工具/生成暖白双眼v2.py)，Pillow 12.3.0。
- 从 1055×1491 展示图按 4×4 圆形单元提取，单元 220×220；圆形遮罩半径 104 px，去除海报灰底和原型屏边框后缩放至 360×360，再限制在半径 164 px 的圆屏安全区内。
- GIF 与 EAF 均使用共享 256 色调色板；EAF 每帧按 12 个 30 行块独立 RLE 编码，黑色背景保持不透明。
- 16 个设计状态为 4 帧；待机动画为 5 帧。GIF/manifest 记录建议帧时长；EAF 播放时的实际帧间隔仍由播放器设置。
- `eaf/manifest.json` 记录每个 EAF 的来源 GIF、尺寸、帧数、建议帧时长、字节数和 SHA-256。

## 使用边界与回退

- `car_reverse` 只有在固件拥有可信倒车输入时才可接入；不能由普通 IMU 加速度推断。
- `car_night` 是风格示例，夜间整体亮度仍由固件统一控制；不能将 `car_signal_lost` 的低亮视觉当成固定语义。
- 缺少或损坏的状态按“同包指定状态 → 同包 `car_cruise` → 固件内置中性表情”回退，并在资源映射/日志中保留真实回退原因。
- 本包当前未复制到 `main/boards/CyberVoc-Board-V2_0/car_packs/`，不会自动进入固件 assets 镜像。
