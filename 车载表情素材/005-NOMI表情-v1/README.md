## 状态覆盖

| 分组 | 状态 |
|---|---|
| 日常行驶 | `car_wake`、`car_move_off`、`car_accelerate`、`car_cruise` |
| 待机动画组 | `car_idle_01`、`car_idle_02`、`car_idle_03` |
| 方向与机动 | `car_turn_left`、`car_turn_right`、`car_turn_end`、`car_reverse` |
| 路况反应 | `car_decelerate`、`car_hard_brake`、`car_bump`、`car_wait` |
| 驻车与降级 | `car_arrive`、`car_sleep`、`car_night`、`car_signal_lost` |

三个待机动画分别使用错拍眨眼、左右视线张望和“单眼眨眨→害羞笑眼”的完整变化，默认等概率选择；每次完整播放结束后再选择下一项，池内至少两项可用时避免立即重复。

## 动作与结束策略

- `car_cruise`、`car_idle_01`～`car_idle_03`、`car_wait`、`car_sleep`、`car_night` 为循环状态。
- 其他状态包含进入、峰值和恢复段，播放后把控制权交回当前实时状态。
- 唤醒从闭眼到睁眼；起步通过笑眼和小幅上下惯性表达；加速、减速通过眼形压缩和前探表达。
- 转向先移动视线再眨眼，青色提示与观看者方向一致；急刹使用挤压、回弹和局部冲击线；颠簸使用左右眼错拍和局部惯性差。
- 黑色背景、核心部件和提示线均限制在半径 165 px 安全范围内；没有高频全屏闪烁。

## 转换参数与容量说明

- GIF 保留完整 120 帧、50 ms 时间轴和 20 FPS；相邻画面不人为合并。
- EAF 从每 2 个 GIF 时间槽抽取 1 帧，保持 6 秒轨迹并建议按 100 ms/帧播放；每项使用统一的 24 色量化和 RLE 编码。
- 本包 EAF 合计 6,870,036 字节，高于当前 V2.0 `assets` 分区 5,500 KiB（5,632,000 字节）上限，尚未进入 `car_packs`。接入固件前需按容量实测进一步降帧、缩短常驻状态或建立白名单，不能直接全包写入 assets。

## 使用边界与回退

- `car_reverse` 只有在固件拥有可信倒车输入时使用，不能由普通 IMU 加速度推断。
- `car_signal_lost` 只表示传感器或数据不可用，不继续显示过期转向或制动状态。
- 缺少或损坏的状态按“同包指定状态 → 同包 `car_cruise` → 固件内置中性表情”回退，并记录真实原因。
- 本包未复制到 `main/boards/CyberVoc-Board-V2_0/car_packs/`，没有进入当前 assets 镜像，也没有执行固件构建、烧录或实机播放。
