# 003 · 暖白双眼 · v1

| 项目 | 值 |
|---|---|
| `pack_id` | `soft_eyes` |
| 画布 | 360×360，黑底 |
| 状态数量 | 16 |
| 视觉 | 两只暖白实心眼睛，无猫耳、胡须、嘴巴或瞳孔 |
| EAF | 8-bit 索引色 BGRA + RLE，12×30 行分块 |
| 验证状态 | 结构与 RLE 回读已检查；当前为四关键姿态原型，尚未打入当前固件，待实机验证 |

本包通过眼形的位移、倾斜、压缩、拉伸和眨眼表达状态，并以少量拖尾、冲击线、回弹弧、星芒和等待点增强动作。分镜、提示词与原设计说明位于 [`../源素材/003-暖白双眼-v1/`](../源素材/003-暖白双眼-v1/)。本设计不是任何汽车品牌的官方素材。

## 状态覆盖

| 分组 | 状态 |
|---|---|
| 日常行驶 | `car_wake`、`car_move_off`、`car_accelerate`、`car_cruise` |
| 方向与机动 | `car_turn_left`、`car_turn_right`、`car_turn_end`、`car_reverse` |
| 路况反应 | `car_decelerate`、`car_hard_brake`、`car_bump`、`car_wait` |
| 驻车与降级 | `car_arrive`、`car_sleep`、`car_night`、`car_signal_lost` |

每个 GIF/EAF 目前只保留四个关键姿态以控制资源体积。方向组眼距、巡航首尾尺寸和个别帧亮度仍需补间前统一；夜间应由固件全局亮度控制，不能把“信号中断必定低亮”固化为语义。

## 目录内容

- `gif/`：16 个四关键姿态预览动画。
- `eaf/`：16 个同名实机候选文件及 `manifest.json`。
- `全部表情预览.gif`：全部状态同步动态总览，中文标签。
- `全部静态表情预览.png`：每个状态的代表姿态，中文标签。

本包接入固件前需先评估 assets 分区容量，并按 [`../02-素材使用规范.md`](../02-素材使用规范.md) 建立显式状态白名单，不能与其他整包无条件同时打入镜像。
