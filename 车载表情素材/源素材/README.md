规则：

- 不从本目录递归收集固件 assets。
- 修改分镜或提示词不会自动改变编号包；完成 GIF/EAF 转换、清单更新和验证后，再建立同编号的新版本。
- 历史转换目录中的 README 只用于旧路径跳转，当前交付说明以编号包 README 和素材根目录规范为准。
- 对外分发任何来自第三方固件、视频或归档的素材前，先确认授权范围。
