# 002 · 薄荷猫咪 · v1

| 项目 | 值 |
|---|---|
| `pack_id` | `cat` |
| 画布 | 360×360，黑底 |
| 状态数量 | 16 |
| 视觉 | 薄荷青猫眼、黑色瞳孔、小猫嘴与短胡须 |
| EAF | 8-bit 索引色 BGRA + RLE，12×30 行分块 |
| 验证状态 | 结构与 RLE 回读已检查；当前为四关键姿态原型，待实机验证和重点状态补间 |

本包由四张 4×4 分镜图转换而来，共 16 种状态。每个 GIF/EAF 目前保留四个关键姿态以控制资源体积，不是最终 20 FPS 连续动画。分镜、提示词与原设计说明位于 [`../源素材/002-薄荷猫咪-v1/`](../源素材/002-薄荷猫咪-v1/)。

## 状态覆盖

| 分组 | 状态 |
|---|---|
| 日常行驶 | `car_wake`、`car_move_off`、`car_accelerate`、`car_cruise` |
| 方向与机动 | `car_turn_left`、`car_turn_right`、`car_turn_end`、`car_reverse` |
| 路况反应 | `car_decelerate`、`car_hard_brake`、`car_bump`、`car_wait` |
| 驻车与降级 | `car_arrive`、`car_sleep`、`car_night`、`car_signal_lost` |

当前固件使用其中巡航、等候、加速、减速、急刹、颠簸、左转、右转和信号中断 9 项。其余状态只有在具备相应输入和生命周期后再接入；特别是倒车不得由普通 IMU 加速度推断。

## 目录内容

- `gif/`：16 个四关键姿态预览动画。
- `eaf/`：16 个同名实机候选文件及 `manifest.json`。
- `全部表情预览.gif`：全部状态同步动态总览，中文标签。
- `全部静态表情预览.png`：每个状态的代表姿态，中文标签。

常驻巡航不应把四帧等时高速循环。选定本风格后，优先为巡航、左右转、急刹和休眠制作平滑补间，并按 [`../01-基础设计规范.md`](../01-基础设计规范.md) 做圆屏实测。
